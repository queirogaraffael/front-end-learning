
# Atividade Prática – Crie sua Página Web com Estilo!

## 🎯 Objetivo

Nesta atividade, você vai criar uma página web completa utilizando **HTML e CSS**, aplicando o que aprendeu sobre estruturação de conteúdo e personalização visual.  
O foco é permitir que você explore livremente as propriedades de estilo do CSS, desenvolvendo sua autonomia criativa.

---

## 📋 Enunciado

Crie uma página web com o **tema que você preferir**, mas que contenha obrigatoriamente os seguintes elementos HTML:

- Um **título principal** (ex: `<h1>`) com um **id** à sua escolha.  
- Um **parágrafo introdutório** sobre o tema da página.  
- Uma **lista não ordenada** com pelo menos **3 itens**.  
- Uma **lista ordenada** com pelo menos **2 itens** (pode ser passos, favoritos, instruções, etc).  
- Pelo menos **dois links externos** que abrem em **nova aba**.  
- Uma **imagem** com **descrição alternativa** (`alt`).  
- Uma **tabela simples** com pelo menos **2 colunas e 2 linhas**.  
- Um **parágrafo final** com uma **classe** (ex: `.rodape`) contendo seu nome, frase ou assinatura.

---

## 🎨 CSS – Liberdade para Estilizar

Crie um arquivo chamado `style.css` e conecte-o ao seu HTML.  
Você deve aplicar estilos livremente, mas precisa usar **ao menos estes tipos de seletores**:

- Um **seletor universal** (`*`)
- Pelo menos um **seletor por tipo** (ex: `body`, `p`, `h1`)
- Pelo menos um **seletor por ID**
- Pelo menos um **seletor por classe**

### 🔧 Propriedades recomendadas para experimentar:

- Cor de fundo e do texto
- Fontes e tamanhos
- Alinhamento de texto e elementos
- Bordas, sombras, arredondamentos

---

## 📦 Entregáveis

- Arquivo `index.html` com a **estrutura da página**
- Arquivo `style.css` com os **estilos aplicados**
- Os arquivos devem estar **funcionando juntos ao abrir no navegador**

---

## 💡 Dica

Essa é uma excelente oportunidade para testar estilos que você viu em aula ou pesquisou por conta própria.  
Não tenha medo de errar — o navegador ajuda a visualizar os resultados rapidamente!
