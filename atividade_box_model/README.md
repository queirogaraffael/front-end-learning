```markdown
# Atividade Prática – HTML, CSS Externo e Box Model

## Instruções

1. Crie uma pasta chamada `atividade_box_model`.
2. Dentro da pasta, crie dois arquivos:
   - `index.html`
   - `estilo.css`

---

## Parte 1 – Estrutura HTML 

No arquivo `index.html`, crie a estrutura básica contendo:

- Um título da página.
- Um cabeçalho principal.
- Um parágrafo introdutório.
- Três blocos/seções com conteúdos distintos.
- Um rodapé.

Cada bloco deve ter identificação clara (via `id` ou `class`) para ser estilizado separadamente.

---

## Parte 2 – CSS Externo 

No arquivo `estilo.css`, crie regras de estilo para:

### A) Blocos de conteúdo

- Aplique em cada bloco:
  - `background-color` diferente
  - `width` e `height` definidos
  - `padding`, `margin` e `border`

### B) Cabeçalho e rodapé

- Defina `cor de fundo` e `cor do texto`
- Defina `padding` interno

### C) Fonte e espaçamento

- Altere a `font-family` do corpo da página
- Adicione `margin` externa geral no `body`

### D) Posicionamento básico (opcional)

- Aplique `display: inline-block` ou `display: block` em pelo menos um dos blocos

---

## Parte 3 – Vinculação dos arquivos 

- Certifique-se de que o CSS está corretamente vinculado ao HTML.

---

## Parte 4 – Testes e ajustes finais 

- Visualize a página no navegador.
- Ajuste o tamanho e o espaçamento dos blocos para melhorar a visualização.
- Verifique se os estilos foram aplicados corretamente a todos os elementos.
```
