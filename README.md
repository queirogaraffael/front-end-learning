# Estudos de HTML e CSS

Este repositório foi criado com o objetivo de organizar e praticar conhecimentos fundamentais de **desenvolvimento front-end**, utilizando **HTML** e **CSS**.

## Estrutura do Repositório

- `atividades flexbox/` – Atividades práticas utilizando Flexbox para layout responsivo.
- `media_query/` – Exemplos de uso de media queries para responsividade em diferentes dispositivos.
- `atividade_box_model/` – Exercícios relacionados ao modelo de caixa (Box Model).
- `perfil-simples-css/` – Página de perfil simples com aplicação de estilos em CSS.
- `pagina-com-css/` – Estrutura de uma página HTML com estilização externa em CSS.
- `box-model-practice/` – Prática e testes com o Box Model.

## Tecnologias Utilizadas

- HTML5
- CSS3

## Objetivo

- Compreender a estrutura básica de uma página web.
- Aprender e praticar o modelo de caixa do CSS.
- Criar layouts responsivos com Flexbox.
- Aplicar media queries para adaptar o conteúdo a diferentes tamanhos de tela.
